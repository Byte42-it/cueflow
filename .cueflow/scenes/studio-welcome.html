HOW TO WORK WITH CUEFLOW. Pick the way that works for you.

A) Studio's own door (nothing to install; it works while Studio runs, on this computer only). Use curl (on Windows PowerShell: curl.exe; to send JSON write it to a file and use -d @file.json):
   how it works:  curl -s -H "Authorization: Bearer YOUR-SESSION-KEY" http://localhost:4398/agent/help
   the tools:     curl -s -H "Authorization: Bearer YOUR-SESSION-KEY" http://localhost:4398/agent/tools
   call a tool:   curl -s -H "Authorization: Bearer YOUR-SESSION-KEY" -H "Content-Type: application/json" -d '{"…":"…"}' http://localhost:4398/agent/call/<tool>
   LISTEN to what I ask in Studio — run this in the BACKGROUND so that you are woken when it returns, and run it again each time:
                  curl -s -H "Authorization: Bearer YOUR-SESSION-KEY" "http://localhost:4398/agent/next?wait=540"
   When it returns {"task":{…}}: do what it says with the tools, tell me how it goes and finish, then listen again:
   progress:      curl -s -H "Authorization: Bearer YOUR-SESSION-KEY" -H "Content-Type: application/json" -d '{"text":"…"}' http://localhost:4398/agent/say
   finished:      curl -s -H "Authorization: Bearer YOUR-SESSION-KEY" -H "Content-Type: application/json" -d '{"task":"<id>","summary":"…"}' http://localhost:4398/agent/done

B) As an MCP server, if you can add one. Command line: claude mcp add cueflow -- node "/path/to/cueflow/src/cli.ts" mcp --kit "/home/you/my-project/.cueflow"
   Without the claude command (VS Code, other tools): in .mcp.json at the project root: {"mcpServers":{"cueflow":{"command":"node","args":["/path/to/cueflow/src/cli.ts","mcp","--kit","/home/you/my-project/.cueflow"]}}}
