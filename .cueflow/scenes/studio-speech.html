Text
To upload a document, open the Documents section from the menu on the left.
Drag a file into the box, or press Choose a file and pick it from your computer. The file appears in the list.
Type a clear title, so you can find the document later.
Press Upload. A progress bar shows how it is going, and when it is done you get a confirmation: the document is now in your archive.
