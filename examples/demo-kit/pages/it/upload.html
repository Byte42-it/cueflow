Quali file

Puoi caricare file PDF, Word e immagini fino a 50 MB ciascuno.

Tipi accettati

PDF, DOCX, JPG e PNG. Gli altri tipi vengono rifiutati prima che il caricamento cominci.

Dimensione

I file più grandi si possono dividere, o comprimere prima del caricamento.

Dopo il caricamento

Il documento compare nell'archivio con il titolo che gli hai dato.

Rinominare

Apri il documento e cambia il titolo: il file non cambia.
